OPTION PRICING ENGINE (Python)
Purpose:
To demonstrate practical understanding of derivative pricing and risk modelling.

It includes:

1. Black-Scholes analytical pricing model
2. Monte Carlo simulation pricing
3. Greeks (Delta, Gamma, Vega)
4. Implied volatility estimation
5. Monte Carlo convergence visualization

Key insight:
- Monte Carlo simulation converges to the Black-Scholes theoretical price as number of simulations increases.

Tools used:
- Python
- NumPy
- Matplotlib


How to run:
1. Install dependencies:
   pip install numpy matplotlib

2. Run:
   python main.py
